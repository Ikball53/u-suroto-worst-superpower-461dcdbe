# Worst Superpower

One line, one useless power: teleportation that only takes you where you
already are. The twist lands in the last words, so the joke needs no setup
or explanation — the power defeats itself.

`main.py` writes the single line to `/output/entry.txt` (UTF-8, no trailing
newline, 1–140 characters).
